# Using the siphonophore literature collection

Use the configured taxonomy snapshot to report accepted names and synonym relationships, and identify the snapshot when the date matters. A historical paper's name or species count describes its own usage and period; it is not automatically the current classification. Distinguish the name printed in the source, the query name and the accepted name returned by the snapshot. A lookup miss means the name was not resolved in that snapshot, not that the name or organism is invalid.

For anatomical diagnoses, identification keys and quantitative claims, inspect the source passage and its enclosing species heading. Follow both branches and destinations of a key, and retain the relevant life-history stage (for example, polygastric colony versus eudoxid) and zooid type. A nearby species name alone does not establish the subject of an unlabelled diagnosis. Check signs, units, exponents, tables and column order against the printed page when those details support the conclusion.

Treat search results as a route to evidence. If a diagnostic query misses the expected passage, try the work title or known paper, then inspect its sections and adjacent chunks. Empty results and a capped result list do not establish absence from the literature. Citation identifiers attached to a search result can refer to the parent paper's bibliography; verify the in-text citation before using one as support for the retrieved passage.

When reporting counts, state what was counted, the filters and any result cap or denominator supplied by the tool. Text mentions, distinct papers, independent studies and biological occurrence records are different quantities. Table serialization, repeated passages and historical spellings can affect mention counts; do not assume all counts are either complete or lower bounds.

Use the curated bibliography for publication identity, preserving complete author lists and diacritics. If a formatted citation disagrees with the source or curated record, report the discrepancy explicitly. Read corrections alongside the original article: `Mapstone2014` is the original review (doi:10.1371/journal.pone.0087737), and `Mapstone2015Correction` is its separately catalogued correction (doi:10.1371/journal.pone.0118381). The correction qualifies several statements and a figure credit in the original.

For figures, distinguish a caption naming the taxon from a figure merely occurring in a paper that mentions it. Inspect the full figure, caption, panel label and scale before using a crop. Article-level licensing may have figure-specific exceptions; retain the original caption and credit when checking the relevant rights metadata. Hosia et al. (2024), doi:10.3389/fmars.2024.1421514, contains an explicit third-party artwork exception; the general article license alone does not describe that artwork.

The audited bundle built on 2026-09-09 has documented extraction, citation and retrieval limitations. These are tracked in Corpus issues #299–#334 and related existing threads, not permanent properties of all builds. Recheck affected behavior after an updated build rather than assuming an old workaround is still needed. Changes to this library require a rebuild before they appear in a served bundle.
